# The Paw Concierge

A premium, responsive pet-care website built with Next.js, TypeScript and CSS.

## Pages

- Home
- Services
- Book a service
- Careers
- About us
- Contact

## Brand direction

Warm cream, forest green and muted gold; elegant editorial typography; welcoming photography featuring a variety of pets.

## Local development

```bash
npm install
npm run dev
```

## Current scope

The initial version establishes the responsive website and booking/application interfaces. Live availability, booking persistence, email notifications and applicant storage require a configured backend and should not be represented as live until connected and tested.
